# 🏦 Lordish Banking System

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)
![License](https://img.shields.io/badge/License-Free-lightgrey)

A simple **Python banking simulation** that allows users to create an account, set a password and PIN, log in securely, and perform basic banking operations such as checking balance, depositing, and withdrawing money.

This project is built using **loops**, **conditional statements**, and **user input/output**, making it perfect for beginners learning Python control flow and logic.
